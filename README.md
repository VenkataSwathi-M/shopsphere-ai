ShopSphere AI is a full-stack, AI-powered e-commerce platform designed to provide an intelligent and personalized shopping experience.

## Technology Stack

Frontend
- React, Vite, JavaScript ES6+
- Material UI
- React Router
- Redux Toolkit
- Axios, Recharts

Backend
- Java 21
- Spring Boot 3
- Spring Security
- Spring Data JPA
- Hibernate
- Maven
- JWT Authentication
- BCrypt

Database and Caching
- PostgreSQL
- Redis
- Flyway

AI Service
- Python
- FastAPI
- Scikit-learn
- Pandas
- NumPy
- OpenCV
- LLM API Integration

DevOps
- Docker
- Docker Compose
- Git
- GitHub
- AWS

## Architecture

text CUSTOMER    | REACT FRONTEND    | SPRING BOOT API    |    +------ SECURITY    |    +------ BUSINESS LOGIC    |    +------ AI CLIENT               |          FASTAPI SERVICE               |            ML / LLM    | DATA ACCESS LAYER    |    +------ POSTGRESQL    |    +------ REDIS
